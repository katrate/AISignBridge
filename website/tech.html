Every Component Explained

🧠
TensorFlow 2.21 + Keras
Deep learning framework powering the 3-model DNN ensemble. Residual MLP blocks, focal loss, AdamW optimizer. CPU-optimized inference via oneDNN.
2.21
✋
MediaPipe Tasks API
State-of-the-art hand landmark detection. 21 3D landmarks per hand at 30+ FPS. Uses the new Tasks API (HandLandmarker) with .task model format.
0.10.31
📷
OpenCV
Camera capture at 640×480, 30 FPS. Frame flipping, drawing overlays for landmarks and connections. BGR-to-RGB conversion for MediaPipe.
4.x
⚛️
PyQt6
Cross-platform desktop UI framework. QThread-based worker threads for camera and speech. Custom dark theme with styled widgets.
6.x
🔊
pyttsx3
Offline text-to-speech engine. Voice selection, speed/volume control. Runs in background thread with phrase queuing for natural speech rhythm.
2.x
🎤
Vosk
Offline speech recognition for bidirectional communication. Listens for spoken letters/numbers and displays corresponding ASL signs.
0.3.x
📊
scikit-learn
Label encoding, train/test splitting, classification metrics. Also used for legacy ensemble model (HistGradientBoosting + SVM + MLP).
1.x
📈
NumPy + Pandas
Data manipulation and numerical computation. Feature engineering with vectorized operations. Dataset loading and preprocessing.
