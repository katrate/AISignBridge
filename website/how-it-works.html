📷 Step 1: Webcam Capture

The application initializes your webcam using OpenCV at 640×480 resolution, 30 FPS. Each frame is flipped horizontally (mirror mode) for an intuitive user experience. The capture runs in a dedicated QThread to avoid blocking the UI. Frames are processed every other frame (15 FPS effective inference rate) to balance CPU usage with responsiveness.

# Frame capture loop (simplified)
cap = cv2.VideoCapture(0, cv2.CAP_DSHOW)
cap.set(cv2.CAP_PROP_FRAME_WIDTH, 640)
cap.set(cv2.CAP_PROP_FRAME_HEIGHT, 480)
while running:
  ret, frame = cap.read()
  frame = cv2.flip(frame, 1) # mirror

✋ Step 2: Hand Landmark Detection

MediaPipe's Tasks API (HandLandmarker) detects 21 3D landmarks on your hand in real-time. These landmarks represent key points: wrist, knuckles (MCP/PIP/DIP), and fingertips for all 5 fingers. The model returns normalized (x, y, z) coordinates for each point, where z represents depth from the camera. Only one hand is tracked per frame for performance.

# MediaPipe Tasks hand landmarking
landmarker = HandLandmarker.create_from_options(options)
detection = landmarker.detect_for_video(mp_image, timestamp_ms)
for hand_landmarks in detection.hand_landmarks:
  # 21 landmarks with .x, .y, .z (normalized)
  draw_landmarks(frame, hand_landmarks)

📐 Step 3: Feature Engineering

The raw 63 values (21×3) go through sophisticated feature engineering in feature_extraction.py. This produces 132 features:

• 42 normalized XY coordinates — bounding-box normalized for scale invariance
• 21 normalized Z coordinates — depth values centered on the wrist
• 69 engineered geometric features — finger extension ratios, tip-to-tip distances, joint angles (PIP/DIP bending), palm geometry, cross-finger distances, and more

Using the same feature extraction code in both training and inference prevents the classic train/inference feature mismatch bug.

🧠 Step 4: Deep Neural Network Ensemble

Three independently trained DNNs each classify the sign. Each network uses a residual MLP architecture:

Input (132) → Dense(512) → BN → ReLU → Drop → ResBlock(512) → ResBlock(256) → ResBlock(256) → ResBlock(128) → ResBlock(128) → ResBlock(64) → Dense(64) → Output (37 classes)

Training uses focal loss (γ=2.0) to focus on hard examples, class weights to balance rare signs, on-the-fly augmentation (noise + masking + scaling), and cosine learning rate decay with warmup. At inference, test-time augmentation (TTA) averages predictions across 20 noise-injected variants for maximum robustness.

# Ensemble prediction with TTA
def predict(features):
  probas = []
  for model in ensemble:
    tta_probas = []
    for _ in range(20): # TTA rounds
      aug = apply_augmentation(features)
      tta_probas.append(model(aug))
    probas.append(mean(tta_probas))
  return mean(probas) # ensemble average

🔊 Step 5: Temporal Smoothing & Speech

Raw predictions are smoothed with an Exponential Moving Average (EMA) (α=0.6) over the full probability vector to prevent flickering between similar signs (e.g., R vs U). A cooldown system prevents duplicate emissions within 5 frames. The system only emits when confidence exceeds a threshold (50% for new signs, 45% for repeats).

Finally, pyttsx3 speaks the recognized sign in a background thread. Multiple detections are accumulated into natural phrases (up to 3 words) before being spoken, creating a fluid conversational rhythm.

Training Pipeline

How the Model Was Trained

1
📥

Data Collection

17,495 samples collected from the Kaggle ASL alphabet dataset (A-Z, 0-9). Raw images processed through MediaPipe for landmark extraction.

2
🔄

Augmentation

Train-only augmentation: mirroring, rotation (±30°), scaling (±15%), aspect stretch, Gaussian jitter. Val/test sets kept clean for honest evaluation.

3
⚖️

Balancing

Each class balanced to 1,200 training samples via targeted augmentation. Class weights applied during training for remaining imbalance.

4
🧪

Training

3 DNNs trained independently with different seeds. Focal loss, cosine decay, early stopping. Best model achieves 95%+ test accuracy.
